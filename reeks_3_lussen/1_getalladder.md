# Getalladder

### Opdracht

Print voor een gegeven getal n ≤ 9 een getalladder met n trappen.

De k-de trap van de ladder bestaat uit de getallen 1 tot en met k (zonder spaties).

**Tip:**

Gebruik print(i, end = “”) om iets te printen zonder dat er na het afdrukken naar een nieuwe regel gesprongen wordt.

### Invoer

1 natuurlijk getal n –> 0 < n <= 9

### Uitvoer

n regels:

-   De k-de regel bestaat uit de getallen 1 tot en met k (zonder spaties)

### Voorbeeld 1

**Invoer**

```
3

```

**Uitvoer**

```
1
12
123

```

### Voorbeeld 2

**Invoer**

```
5

```

**Uitvoer**

```
1
12
123
1234
12345

```
